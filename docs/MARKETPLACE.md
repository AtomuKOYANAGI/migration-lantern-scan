## English

**Name:** Migration Lantern Scan

**Short description:** Find documented OpenAI and Anthropic model, endpoint, and Python SDK deprecations before they break production.

Migration Lantern Scan statically parses Python repositories, reports impacted files and lines, links each finding to provider-owned evidence, shows published retirement dates and severity, and exports JSON and Markdown for CI. It does not execute repository code or send source to an external service.

**Support:** GitHub Issues for reproducible bugs without proprietary code; private GitHub Security Advisories for vulnerabilities.

**Workflow coordinate:** `AtomuKOYANAGI/migration-lantern-scan@v0.1.0`
